# Application audit — October 16, 2026

## Scope and evidence

Repository: Darkwolf21g/btc15-tape. Baseline main: `dfd4092b5439c58bbd641d5b22347c721254d274` (deployed PR #16). All 32 baseline text files were verified against GitHub blob hashes before review. The nine tracked PNGs are historical test screenshots, not application source; their paths/hashes were inventoried, but they were not treated as evidence of the current UI. No AGENTS.md exists in the repository tree. The previous working copies and ENGINEERING_REVIEW.md were preserved.

This is a repository-wide source, configuration, data-flow and test-coverage audit. It is not proof that the application has no defects. Live entitlements, production session history, current upstream API contracts, account-specific fees and trading performance require access not supplied to this environment. No production/demo orders were placed, secrets changed, experiment enabled, merge performed or production deployment requested by this audit.

## Validation and reproduction record

- Baseline: all 156 deterministic tests and npm run check passed. No lint or TypeScript configuration exists.
- Before fixes: a targeted run produced 9 failures / 80 passes against the baseline. Those failures demonstrated startup/control/Off races, malformed config handling, fractional fills, invalid index input, inactive-market buy signals and missing request deadlines. The deadline test was subsequently narrowed to its actual finding; public exchange/market reads intentionally do not require a feed token.
- The expanded suite adds real-source tests for all eleven venue adapters, active/stale contract gating, retired sockets, HTML escaping, checkpoint cancellation, CLI dataset preservation and mirror checks. The CLI-body test uses real filesystem I/O with isolated argv/output; it does not assert a production network integration.
- Local Python syntax checks cover all manual/smoke scripts. Local Node/source results and remote CI results are recorded in the final evidence update below.
- Local npm registry requests fail at the platform-provided proxy. No project proxy override exists and none was introduced. npm audit returned no advisory data; this is not a clean vulnerability scan.
- Local workerd tests cannot start because npm installation is unavailable (wrangler/Miniflare missing). Default Playwright browser is absent; attempting the installed /usr/bin/chromium also fails with sandbox setsockopt/SIGTRAP before page load. Local browser verification did not pass.
- Fixture browser smoke checks make no production requests and submit no orders. They assert tape warm-up, full BRTI average, contract WAIT gating, mobile document width, independent session refresh and stale-result/manual-stop controls. Screenshots are artifacts for review, not evidence of real feeds.
